# Colton Batts Portfolio

Production-ready Next.js portfolio website for coltonbatts.com. Features premium motion graphics and video production work.

## Technology Stack

- **Framework:** Next.js 15 (React 18)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Deployment:** Vercel
- **Hosting:** coltonbatts.com

## Features

✅ **Responsive Design** — Mobile-first approach, optimized for all screen sizes  
✅ **Performance** — Fast load times, optimized images, smooth animations  
✅ **SEO Ready** — Meta tags, structured data, Open Graph support  
✅ **Design System** — "Colton" font (Inter Bold) with consistent styling  
✅ **Portfolio Grid** — 3 flagship projects with individual case studies  
✅ **Contact Form** — Client-side form handling  
✅ **Dark Mode** — Premium dark aesthetic throughout  

## Getting Started

### Installation

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Open in browser
# http://localhost:3000
```

### Build for Production

```bash
npm run build
npm start
```

## Deployment

### Option 1: Deploy to Vercel (Recommended)

1. **Push to GitHub First**
   ```bash
   git init
   git add .
   git commit -m "Initial commit: portfolio website"
   git remote add origin https://github.com/YOUR_USERNAME/coltonbatts-portfolio.git
   git push -u origin main
   ```

2. **Connect to Vercel**
   - Visit [vercel.com](https://vercel.com)
   - Click "New Project"
   - Import your GitHub repository
   - Select "Next.js" as framework
   - Click "Deploy"

3. **Point Domain to Vercel**
   - In Vercel dashboard, go to Settings → Domains
   - Add `coltonbatts.com`
   - Update your domain registrar's DNS:
     - **A Record:** `76.76.19.165`
     - **CNAME:** `cname.vercel-dns.com`
   - (Or use Vercel's nameservers for full management)

### Option 2: Manual Build & Deploy

```bash
# Build
npm run build

# Test production build locally
npm start

# Deploy to your hosting of choice
# (instructions vary by provider)
```
